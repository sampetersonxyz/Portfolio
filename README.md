# Portfolio
Portfolio

V!s!on downloads are loaded from the latest published GitHub release in
`petesamerson/V-s-on`. Attach Windows `.exe`, `.msi`, `.msix`, or a ZIP whose
name includes `windows`, `win64`, `win32`, or `win-x64`, and Android `.apk`
files to that release. Multiple architecture variants are shown separately.
Publish a newer release to update the website's download links automatically.
Drafts and prereleases are excluded. This provides updated downloads, not
automatic updates inside installed apps. If GitHub is unavailable, visitors
can use the releases link.
